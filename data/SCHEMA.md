# 数据规范(给所有数据生成代理)

输出:**纯 JSON 文件,UTF-8,无注释、无 Markdown 围栏、无尾逗号**。直接用 Write 工具写到指定路径。

顶层是一个对象: `{ "brands": [ ... ] }`。

## 品牌对象

```json
{
  "id": "bmw",                       // 唯一 id:小写英文/拼音,不含空格
  "name": "宝马",
  "nameEn": "BMW",
  "domain": "bmw.com",               // 官网域名(用于自动抓 logo,尽量给主域名)
  "categoryId": "auto",              // 必须是分配的品类 id
  "country": "德国",
  "founded": 1916,                   // 数字年份
  "hq": "慕尼黑",
  "tier": "豪华",                    // 档次定位,如:顶奢/奢华/高奢/轻奢/大众/国民/平价
  "tags": ["德系", "操控", "运动"],
  "slogan": "纯粹驾驶乐趣",           // 一句话,可为空字符串
  "desc": "60–100 字的一句话简介:它是谁、以什么闻名、地位如何。",
  "story": "150–260 字的品牌故事,2 段,用 \n 分隔。讲起源、标志事件、现状。",
  "products": [ ... ]
}
```

## 产品对象(每品牌 5–10 个,选最知名/最有代表性的产品线)

```json
{
  "id": "bmw-3series",               // 品牌id-产品英文小写
  "name": "3系",
  "nameEn": "3 Series",
  "type": "中型轿车",                 // 短类型词(用于筛选和图标)
  "price": { "min": 299900, "max": 399900, "currency": "CNY", "label": "厂商指导价" },
  "desc": "40–90 字介绍:定位、亮点、口碑。",
  "highlights": ["直列六缸", "后驱操控"],   // 2–4 个短标签
  "tags": ["运动"],
  "image": null                      // 统一 null(前端自己配图)
}
```

## 价格规则
- 一律人民币整数(元)。汽车用指导价区间;奢侈品用官网/专柜参考价区间;手表用公价区间;食品饮料用单件零售价。
- 价格给**量级准确**的区间即可,不确定就放宽区间。
- label 可选:`厂商指导价` / `官网参考价` / `专柜参考价` / `公价` / `零售参考价` / `单杯参考价`。

## 硬性要求
1. 只写分配给你的品牌清单,不要自行增删品牌。
2. 产品 id、品牌 id 全局唯一(id 里带品牌前缀)。
3. 内容必须真实可靠:不确定的细节宁可不写,不要编造具体数字。
4. 所有文本中文(品牌英文名/产品英文名除外)。
5. 不要输出 Markdown,不要解释,直接 Write JSON 文件。
6. 文件较大时可分两次 Write:先写前一半品牌,再用 Edit 追加(rest 部分替换为后半)。保证最终文件是完整合法 JSON。
